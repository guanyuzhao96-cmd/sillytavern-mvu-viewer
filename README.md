# MVU 数据查看器 · 原生扩展 v1.1.0

## 安装
现在支持通过仓库链接安装。在酒馆“扩展程序 → 安装扩展程序”中粘贴：

https://github.com/guanyuzhao96-cmd/sillytavern-mvu-viewer

安装完成后刷新酒馆，进入聊天页面，点击右下方“MVU 数据”按钮打开。仍需启用酒馆助手和当前卡的 MVU 变量框架，不需要再导入本工具的脚本 JSON。若此前导入过 v1.0 的 MVU 查看器脚本，请将该脚本停用，避免两个入口同时运行；不要停用你的系统结算脚本或 MVU 框架。

如果安装返回“服务器维护中”的 HTML，而不是正常安装结果，说明云酒馆服务返回了维护页面，仓库文件不能修复这种服务端故障。请待服务恢复再尝试。若扩展安装成功但没有数据，请启用酒馆助手/MVU，再刷新面板。

原生版只使用本仓库文件，不远程加载额外代码。最新楼编辑、导入导出等行为沿用 v1.0。用户云酒馆安装、刷新持久化及手机布局尚待现场验收。

### 旧版脚本安装方式（可选，与原生版二选一）
在酒馆助手的脚本管理中导入 `MVU数据查看器_导入酒馆助手_v1.0.json`，启用脚本。推荐导入全局脚本方便用于不同角色卡，也可先放在当前卡的脚本列表。当前卡必须已有可用 MVU；本工具不替代变量框架，也不需要新世界书或额外 API。不要停用原来的系统结算或渲染器。

点击酒馆助手的“MVU 数据”按钮，或页面右下方“MVU 数据”悬浮入口。若看不到入口，刷新酒馆页面并检查脚本已启用；多个同名版本只启用一个。

## 查看
顶部选择消息楼层，默认实际最新消息。角色、场景、任务、系统与技能、商店与物品、图鉴、成就与奖励、事件、论坛分开显示；“全部字段”保留未知字段。中文适配来自潍坊学院 v1.15，其他卡结构不同仍可使用完整字段目录。

对象/列表点击展开，完整值和下属字段均可查看。搜索查全部实际数据，不限当前模块。值 0、false、null、空字符串与未保存字段分别处理，不用默认值冒充实存数据。论坛未保存时显示无数据，不生成内容。成就显示实际账本，工具不执行成就计算或发奖。

“本轮变化”比较所选楼和上一份有 stat_data 的 AI 楼，包括草稿。不是 AI 更新命令执行日志，不能仅凭差异认定出错原因。原始数据展示所选消息完整变量表；其中 stat_data 含当前编辑草稿。

## 编辑
仅聊天实际最新消息楼可编辑。最新用户楼无数据时不会回退编辑此前 AI 楼。点击字段“编辑”，选择数据类型，加入草稿；新增字段使用 JSON Pointer 路径（/roles/角色名/affection），父对象需存在。对象和数组可整组修改，支持删除字段。

点击“保存修改”先核对差异，再“确认保存”。生成/MVU 更新中、新消息、重新生成、切换消息页或聊天、原变量表变化时拒绝保存。保存只改 stat_data，不触发奖励、扣点、任务完成或脚本结算。下一次正常剧情仍会受到原结算规则约束，手改数值可能被规则校正。

“撤销上次保存”只撤销本工具在当前打开期间的上一笔保存；之后任何变量变化将阻止撤销。它不是长期历史备份，重要数据请先导出。保存后的页面读取本工具会更新；其他角色卡 UI 可能需要刷新。刷新酒馆后再查一次确认持久化。

## 导入导出
导出所选楼实际保存的数据，不导出未保存草稿。文件带格式版本、导出时间、聊天来源和完整变量表。浏览器不允许自动复制时提供手动全选复制窗口。

导入 JSON 支持本工具备份、带 stat_data 的完整变量表或纯 stat_data 对象，最大 20 MB。只把 stat_data 应用到当前最新楼；备份中的 MVU 元信息及其他脚本数据不覆盖当前消息。

默认“合并”保留未提供字段；“替换”会删除备份中缺少的实际字段。两种方式都先加入草稿，显示完整差异，确认保存才写入。将别的聊天备份导入当前聊天也遵循这个规则；来源记录不会改变目标楼层。

## 预览与验收
`MVU数据查看器_交互预览_v1.0.html` 使用正式核心和 UI 源码，仅数据适配器换成内存演示。演示保存不写入你的酒馆，关闭网页即丢失。

真实酒馆需验收：导入后入口；读取正确楼层；改最新楼好感并保存；刷新后仍保留；历史只读；生成期间拒写；切 swipe 拒写；导出再导入同一份数据无差异；现有状态栏读取和其他插件兼容。尚未在用户云酒馆或手机 Safari 验收。

## 源码测试

运行 `python3 build.py` 重建导入 JSON 与演示 HTML。纯数据测试运行 `node test.cjs`；DOM/宿主模拟测试需要安装 jsdom，可用 `npm install --no-save jsdom` 后运行 `node dom-test.cjs` 和 `node host-test.cjs`。真实浏览器测试另需 playwright 与 Chromium，运行 `node ui-test.cjs`。浏览器测试尚未在发布环境执行。

原生适配测试：`node native-test.cjs`（需要 jsdom）。
