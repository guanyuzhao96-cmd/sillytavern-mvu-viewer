## 查看
顶部选择消息楼层，默认实际最新消息。角色、场景、任务、系统与技能、商店与物品、图鉴、成就与奖励、事件、论坛分开显示；“全部字段”保留未知字段。中文适配来自潍坊学院 v1.15，其他卡结构不同仍可使用完整字段目录。

对象/列表点击展开，完整值和下属字段均可查看。搜索查全部实际数据，不限当前模块。值 0、false、null、空字符串与未保存字段分别处理，不用默认值冒充实存数据。论坛未保存时显示无数据，不生成内容。成就显示实际账本，工具不执行成就计算或发奖。

“本轮变化”比较所选楼和上一份有 stat_data 的 AI 楼，包括草稿。不是 AI 更新命令执行日志，不能仅凭差异认定出错原因。原始数据展示所选消息完整变量表；其中 stat_data 含当前编辑草稿。

## 编辑
仅聊天实际最新消息楼可编辑。最新用户楼无数据时不会回退编辑此前 AI 楼。点击字段“编辑”，选择数据类型，加入草稿；新增字段使用 JSON Pointer 路径（/roles/角色名/affection），父对象需存在。对象和数组可整组修改，支持删除字段。

点击“保存修改”先核对差异，再“确认保存”。生成/MVU 更新中、新消息、重新生成、切换消息页或聊天、原变量表变化时拒绝保存。保存只改 stat_data，不触发奖励、扣点、任务完成或脚本结算。下一次正常剧情仍会受到原结算规则约束，手改数值可能被规则校正。

“撤销上次保存”只撤销本工具在当前打开期间的上一笔保存；之后任何变量变化将阻止撤销。它不是长期历史备份，重要数据请先导出。保存后的页面读取本工具会更新；其他角色卡 UI 可能需要刷新。刷新酒馆后再查一次确认持久化。

## 导入导出
导出所选楼实际保存的数据，不导出未保存草稿。文件带格式版本、导出时间、聊天来源和完整变量表。浏览器不允许自动复制时提供手动全选复制窗口。

导入 JSON 支持本工具备份、带 stat_data 的完整变量表或纯 stat_data 对象，最大 20 MB。只把 stat_data 应用到当前最新楼；备份中的 MVU 元信息及其他脚本数据不覆盖当前消息。

默认“合并”保留未提供字段；“替换”会删除备份中缺少的实际字段。两种方式都先加入草稿，显示完整差异，确认保存才写入。将别的聊天备份导入当前聊天也遵循这个规则；来源记录不会改变目标楼层。
